\section{Pemetaan Hamiltonian Ising}
\label{sec:4_3_pemetaan_hamiltonian}

Perubahan permasalahan dari domain klasik menuju komputasi kuantum memerlukan alat transformasi yang menghubungkan utilitas ekonomi dengan energi kuantum, yakni melalui formulasi \textit{Quadratic Unconstrained Binary Optimization} (QUBO). Proses transformasi ini diawali dengan mengonversi fungsi potensial $\Phi(\vec{x})$ menjadi fungsi energi minimisasi $E(\vec{x}) = -\Phi(\vec{x})$ guna menyesuaikan dengan prinsip variasi algoritma VQE
\begin{equation}
    \begin{split}
    E(\vec{x}) &= -\Phi(\vec{x}) \\
    &= -\left( \frac{1}{k} \vec{\mu}^T \vec{x} - \frac{\gamma}{2k^2} \vec{x}^T \Sigma \vec{x} \right).
    \label{eq:energy_function}
    \end{split}
\end{equation}

Berdasarkan formulasi matematis dan konversi rumusan \textit{Quadratic Unconstrained Binary Optimization} (QUBO) menuju matriks Hamiltonian Ising yang telah dijabarkan secara terperinci pada Bab 2, keseluruhan parameter model klasik tersebut dipetakan secara eksak menjadi sekumpulan variabel interaksi spin fisis. Transformasi ekuivalen matematis ini pada akhirnya berhasil mensintesis sebuah struktur komprehensif yang secara langsung direpresentasikan sebagai bentuk fungsional Hamiltonian Ising murni guna memfasilitasi kebutuhan operasional algoritma optimasi portofolio berbasis kuantum. Pada formulasi operator uniter akhir ini, parameter $\hat{\mathcal{H}}$ mendefinisikan bentuk ruang lingkup total Hamiltonian Ising yang merangkum keseluruhan lanskap titik-titik ekuilibrium energi konfigurasi dari sistem kuantum yang sedang disimulasikan secara \textit{real-time}. 

Dalam struktur pemetaan tersebut, variabel operasional $h_i$ secara spesifik difungsikan sebagai representasi koefisien spin linear yang mendikte tingkat persentase bias probabilitas pemilihan pada tiap-tiap agen qubit secara individual yang saling terisolasi. Sementara itu, parameter operasional deterministik $J_{ij}$ dirancang untuk merepresentasikan kuantitas koefisien interaksi spin silang yang mengatur secara tegas derajat keterikatan volatilitas risiko korelasi finansial antara dua aset yang saling berbeda identitas, sedangkan parameter $C$ sekadar berfungsi mekanis sebagai konstanta skalar pemerataan nilai \textit{offset} energi absolut bagi seluruh penjuru konfigurasi sistem. Derivasi parameter teoretis murni ini lantas memicu transisi implementasi fungsional karena struktur matriks harus diaplikasikan ke dalam ekosistem perangkat keras nyata untuk dieksekusi secara iteratif.

\subsection{Implementasi Numerik Hamiltonian Ising}

Pada aplikasinya, struktur persamaan Hamiltonian kuantum lengkap yang dibangun untuk mewakili sistem dua aset ($N=2$) dengan rasio kardinalitas portofolio konstan ($k=1$) dapat disederhanakan dengan mengeliminasi notasi jumlahan sigma kompleks. Penjabaran persamaan ekuivalen untuk sistem berskala kecil ini memungkinkan proses verifikasi konseptual secara manual terhadap interaksi antara koefisien bias linear dan interaksi kuadratik tanpa membebani memori komputasi secara berlebih. Sedangkan untuk menavigasi kompleksitas dinamika pasar pada sistem bervolume lebih besar dengan empat aset observasi ($N=4, k=2$), jaringan interaksi antar-spin secara simultan akan langsung bermutasi menjadi jauh lebih kompleks akibat meluasnya variasi korelasi sektoral. Konstruksi ekspansi aljabar untuk kedua dimensi matriks sistem yang diuraikan ini dapat ditinjau secara langsung melalui turunan matematis struktural berikut
\begin{equation}
    \hat{\mathcal{H}}_{N2} = h_1 \hat{Z}_1 + h_2 \hat{Z}_2 + J_{12} \hat{Z}_1 \hat{Z}_2 + C
\end{equation}
sedangkan untuk iterasi matriks interaksi aset majemuk:
\begin{equation}
    \begin{split}
    \hat{\mathcal{H}}_{N4} =& h_1 \hat{Z}_1 + h_2 \hat{Z}_2 + h_3 \hat{Z}_3 + h_4 \hat{Z}_4 + J_{12} \hat{Z}_1 \hat{Z}_2 + J_{13} \hat{Z}_1 \hat{Z}_3 + J_{14} \hat{Z}_1 \hat{Z}_4 \\
    &+ J_{23} \hat{Z}_2 \hat{Z}_3 + J_{24} \hat{Z}_2 \hat{Z}_4 + J_{34} \hat{Z}_3 \hat{Z}_4 + C
    \end{split}
\end{equation}

Sebagai sebuah ilustrasi operasional numerik yang konkret pada jendela evaluasi pengujian tahap pertama, formulasi bentuk nilai Hamiltonian untuk sampel observasi sistem berskala dua aset secara presisi dapat diekstraksi. Kemudian, saat prosedur komputasi identik diaplikasikan pada dimensi ruang sistem empat aset pada periode jendela analitik yang sama persis, algoritma optimasi akan merumuskan persamaan konfigurasi Hamiltonian dengan nilai derajat kebebasan yang jauh lebih komprehensif. Pada analisis hasil perhitungan tersebut, magnitudo nilai koefisien fisis interaksi yang mencatatkan probabilitas di sekitar $J_{ij} \approx 0,5$ secara absolut terbukti sangat didominasi oleh pengaruh amplifikasi parameter penalti konstan anggaran $A$. Keberadaan nilai ambang batas penalti ini pada akhirnya berfungsi untuk menciptakan tembok penghalang energi yang teramat curam bagi setiap konfigurasi susunan mikrokondisi yang dengan sengaja melanggar pakem kendala kelayakan fraksi anggaran portofolio yang diizinkan.

Guna mengakomodasi perakitan operator Hamiltonian Ising secara otomatis dalam ranah komputasi kuantum berbasis sirkuit terprogram, proses penyusunan matriks diimplementasikan murni secara algoritmik menggunakan fungsi penyusun Hamiltonian dari pustaka \textit{PennyLane}. Blok instruksi pemrograman dinamis ini dirancang untuk membaca matriks koefisien bias linear dan koefisien interaksi spin sebagai himpunan parameter masukan, lalu mengonversinya menjadi kumpulan komponen tensor Pauli-Z kuantum murni. Melalui proses penyisipan syarat presisi komputasi \textit{floating-point} sekecil $10^{-12}$, fungsi ini bertindak sangat esensial dalam menyingkirkan elemen matriks nol sehingga proses eksekusi simulasi sirkuit kuantum dapat terhindar dari redundansi operasional memori berlebih yang tidak relevan secara fisis. Keseluruhan modul pemrograman fungsional ini secara komprehensif mendokumentasikan kapabilitas algoritma dalam merakit arsitektur operator uniter pada lanskap energi VQE secara presisi sebagaimana dapat disaksikan pada Daftar Kode \ref{lst:build_hamiltonian}.

\begin{lstlisting}[language=Python, caption={Skrip perakitan operator Hamiltonian Ising dinamis menggunakan pustaka \textit{PennyLane}}, label={lst:build_hamiltonian}]
import pennylane as qml

def build_hamiltonian_total(h_total, J_total, n_assets, offset=0.0):
    """
    Membangun operator Hamiltonian Ising dari parameter h_i dan J_ij,
    termasuk konstanta pergeseran energi C_Ising.
    H = sum(h_i * Z_i) + sum(J_ij * Z_i * Z_j) + offset * I
    """
    coeffs = []
    obs    = []

    # Suku Bias (h_i * Z_i)
    for i in range(n_assets):
        if abs(h_total[i]) > 1e-12:
            coeffs.append(float(h_total[i]))
            obs.append(qml.PauliZ(i))

    # Suku Interaksi (J_ij * Z_i * Z_j)
    for i in range(n_assets):
        for j in range(i + 1, n_assets):
            if abs(J_total[i, j]) > 1e-12:
                coeffs.append(float(J_total[i, j]))
                obs.append(qml.PauliZ(i) @ qml.PauliZ(j))

    # Suku Konstanta (offset * Identity)
    if abs(offset) > 1e-12:
        coeffs.append(float(offset))
        obs.append(qml.Identity(0))

    if len(coeffs) == 0:
        coeffs.append(0.0)
        obs.append(qml.Identity(0))

    return qml.Hamiltonian(coeffs, obs)
\end{lstlisting}
