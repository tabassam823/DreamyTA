\section{Validasi Solusi melalui Algoritma \textit{Brute Force}}
\label{sec:4_9_validasi_benchmark}

\subsection{Kalkulasi Energi Kombinatorial}

Algoritma komputasional kuantum iteratif VQE yang diimplementasikan pada riset penelitian ini secara esensial merupakan sebuah kerangka konseptual yang membutuhkan mekanisme prosedur pengujian validasi struktural guna mengonfirmasi tingkat akurasi solusi portofolio yang dihasilkan. Prosedur kalkulasi validasi tersebut secara operasional didesain dengan memprioritaskan keterlibatan eksekusi metode pencarian \textit{brute force} yang bekerja mengevaluasi keseluruhan ruang keadaan kombinatorial secara deterministik. Melalui penerapan protokol prosedur pembandingan ini, amplitudo kuantum yang diformulasikan pada simulasi sirkuit VQE dijamin pasti bermuara pada koordinat parameter aset ekuilibrium energi terendah yang valid. Dengan demikian, algoritma pencarian \textit{brute force} ini secara nyata memegang peran pembuktian yang krusial sebagai acuan mutlak evaluasi efisiensi operasional sirkuit VQE terhadap lanskap fungsi objektif kuantum sebenarnya.

Metode \textit{brute force} beroperasi dengan mengkalkulasi matriks turunan nilai ekspektasi energi dari operator Hamiltonian sistem secara komprehensif bagi setiap kemungkinan konfigurasi portofolio biner di dalam ruang Hilbert. Sebagai representasi operasional pada simulasi pengujian sampel data jendela observasi Januari 2021 untuk sistem dua aset, implementasi matematis ditetapkan menggunakan parameter penalti senilai $A = 5,0$. Kalkulasi fungsi energi objektif fungsional komputasi arsitektur matriks portofolio fisis $E(\vec{x})$ lantas dieksekusi secara berurutan dan terstruktur penuh ke dalam keempat status matriks keadaan probabilitas observabel stabilitas basis komputasi fungsional ekuivalen deterministik sebagai fungsi matriks berdimensi ekuilibrium operasional presisi riil konstan terukur berikut:
\begin{enumerate}
    \item \textbf{Keadaan $|00\rangle$ (Tanpa Aset):} 
    $E = \text{Obj}(0,0) + A(0+0-1)^2 = 0 + 5,0(1) = 5,0$.
    \item \textbf{Keadaan $|01\rangle$ (Hanya ADRO):} 
    $E = \text{Obj}(0,1) + A(0+1-1)^2 = -0,1890 + 0 = -0,1890$.
    \item \textbf{Keadaan $|10\rangle$ (Hanya BBCA):} 
    $E = \text{Obj}(1,0) + A(1+0-1)^2 = -0,3498 + 0 = -0,3498$.
    \item \textbf{Keadaan $|11\rangle$ (Kedua Aset):} 
    $E = \text{Obj}(1,1) + A(1+1-1)^2 \approx -0,5333 + 5,0 = 4,4667$.
\end{enumerate}
Rangkaian pembuktian matriks komputasi kuantum numerik stabilitas fungsional ekuivalen observabel komprehensif matriks tersebut menempatkan status arsitektur observabel sistem $|10\rangle$ sebagai fungsional konfigurasi stabilitas dengan tingkat distribusi energi ekuilibrium terendah yang berimplikasi matriks presisi arsitektur riil deterministik presisi terhadap akurasi ekuivalen algoritma fungsional optimasi portofolio VQE.

\subsection{Implementasi \textit{Brute Force} Berbasis \textit{Python}}

Guna mendemonstrasikan bagaimana pencarian solusi eksak ini ditranslasikan dari model matematika menuju instruksi algoritma pemrograman secara utuh, blok modul pencarian \textit{brute force} tersebut didefinisikan ke dalam bentuk skrip komputasional \textit{Python}. Konstruksi utama skrip ini secara fungsional difokuskan pada pemanfaatan pustaka \textit{itertools} yang mampu membangkitkan dan menyisir keseluruhan kemungkinan \textit{bitstring} secara leksikografis dengan efisiensi memori yang sangat terukur optimal. Pada setiap untaian elemen kombinatorial \textit{bitstring} yang diproses, program secara sistematis langsung mengukur skor fungsi parameter probabilitas energi ekuivalen komputasi berdasarkan fungsi interaksi observabel bias serta nilai faktor penalti yang diberlakukan deterministik. Rangkaian fungsional algoritma tersebut secara mandiri akan senantiasa menyimpan dan terus memperbarui riwayat presisi probabilitas komputasional deterministik fungsional dari status \textit{bitstring} dengan estimasi ekuivalensi observabel matriks energi iteratif kumulatif komprehensif yang diyakini secara mutlak operasional paling minimum dan stabil.

Algoritma komprehensif proses validasi deterministik ini tidak hanya sebatas dirancang secara fungsional utuh guna menghitung dimensi lanskap stabilitas probabilitas nilai ekuilibrium energi minimum global yang terbebas mutlak dari segenap kekangan batasan operasional parameter, namun juga difungsikan secara komputasional dalam menelusuri nilai ekspektasi matriks minimum fisis riil yang patuh terhadap restriksi ketat komponen kardinalitas anggaran. Melalui mekanisme segregasi pelacakan sistem terhadap kedua bentuk indikator metrik variansi fisis energi tersebut, performa hasil luaran komputasional observabel fungsi ekuivalen sirkuit iterasi adaptif VQE dapat divalidasi silang deterministik secara murni dengan berlandaskan rasio perbandingan fungsional matriks probabilitas parameter arsitektur yang sangat transparan. Konsep ekuivalensi fungsional arsitektur pendekatan operasional iterasi fungsi \textit{brute force} klasik konstan deterministik ini memastikan bahwa operasional VQE tersebut memiliki ketangguhan fungsi analitis yang tinggi melampaui aproksimasi numerik saat merepresentasikan topologi hambatan stabilitas kuantum komprehensif arsitektur fasa ekuilibrium dimensi besar sirkuit portofolio matriks riil sesungguhnya. Seluruh skrip program operasional fungsional pelacakan analitis deterministik stabilitas observabel deterministik fungsi perhitungan parameter algoritma iteratif tersebut kemudian didefinisikan matriks arsitektur fungsional secara komprehensif di dalam implementasi Daftar Kode \ref{lst:brute_force_code} guna menyajikan perbandingan eksekusi teknis yang riil mutlak.

\begin{lstlisting}[language=Python, caption={Skrip komputasi algoritma \textit{brute force} untuk validasi lanskap energi portofolio pada arsitektur kuantum}, label={lst:brute_force_code}]
import numpy as np
import pandas as pd
from itertools import product

def calculate_ising_energy(x, h, J, C_Ising):
    n_assets = len(x)
    Z = 1 - 2 * np.array(x)
    
    # Suku Bias: sum(h_i * Z_i)
    energy_bias = np.sum(h * Z)
    
    # Suku Interaksi: sum(J_ij * Z_i * Z_j)
    energy_interaction = 0
    for i in range(n_assets):
        for j in range(i + 1, n_assets):
            energy_interaction += J[i, j] * Z[i] * Z[j]
            
    return energy_bias + energy_interaction + C_Ising

def brute_force_portfolio(n_assets, h, J, C_Ising, K=2):
    best_global_e = float('inf')
    best_global_bs = None
    best_constrained_e = float('inf')
    best_constrained_bs = None
    
    # Eksplorasi 2^N
    for bit_tuple in product([0, 1], repeat=n_assets):
        x = np.array(bit_tuple)
        energy = calculate_ising_energy(x, h, J, C_Ising)
        bit_str = "".join(map(str, bit_tuple))
        
        if energy < best_global_e:
            best_global_e = energy
            best_global_bs = bit_str
            
        if sum(x) == K:
            if energy < best_constrained_e:
                best_constrained_e = energy
                best_constrained_bs = bit_str
                
    return best_constrained_bs, best_constrained_e
\end{lstlisting}
