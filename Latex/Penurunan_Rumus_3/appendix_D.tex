\section{Ekspansi Penalti Polinomial dalam Ruang Spin}
Suku penalti $P(x) = A(\sum x_i - K)^2$ ditransformasikan ke ruang spin melalui $\sum x_i = \frac{N}{2} - \frac{1}{2}\sum \sigma_i^z$.
Gunakan variabel bantu $K' = \frac{N}{2} - K$:
\begin{equation}
\begin{aligned}
P(\sigma) &= A \left( K' - \frac{1}{2}\sum \sigma_i^z \right)^2 \\
&= A \left( K'^2 - K' \sum \sigma_i^z + \frac{1}{4} \left(\sum \sigma_i^z\right)^2 \right)
\end{aligned}
\end{equation}
Ekspansi suku kuadratik $\left(\sum \sigma_i^z\right)^2$:
\begin{equation}
\left(\sum \sigma_i^z\right)^2 = \sum (\sigma_i^z)^2 + 2\sum_{i<j} \sigma_i^z \sigma_j^z = N + 2\sum_{i<j} \sigma_i^z \sigma_j^z
\end{equation}
Substitusi kembali:
\begin{equation}
P(\sigma) = A \left( K'^2 - K' \sum \sigma_i^z + \frac{N}{4} + \frac{1}{2}\sum_{i<j} \sigma_i^z \sigma_j^z \right)
\end{equation}
Pengelompokan koefisien:
\begin{equation}
P(\sigma) = \sum_{i<j} \frac{A}{2} \sigma_i^z \sigma_j^z - \sum_i (A K') \sigma_i^z + A(K'^2 + N/4)
\end{equation}
Ini memberikan kontribusi penalti pada parameter $J_{ij}$ dan $h_i$ secara konsisten.
